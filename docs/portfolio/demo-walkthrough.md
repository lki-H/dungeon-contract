## 约2—3分钟现场演示脚本

以下是现场操作安排，不是已完成整局录像的说明。完整地下城通常超出这个时间，战斗可展示已启动的当前局；结果使用真实完成后的记录，不伪造胜利或描述为2分钟通关。

| 时间 | 操作与讲解 | 后端切点 |
| --- | --- | --- |
| 0:00—0:25 | 大厅或控制页登录，选方案与合同，说明客户端／权威／Go分工 | JWT／会话、服务保存的玩家状态 |
| 0:25—0:55 | 展示准备、匹配提案与接受，再进入已加载战斗 | 队伍版本、活动锁、指纹与票据 |
| 0:55—1:30 | 移动、攻击和一个技能；有第二位操作者时展示队友／救援 | 客户端发意图，Unity裁决，Go接业务事实 |
| 1:30—2:05 | 展示重发回执路径，查询真实已完成局的结果 | 身份+指纹、received／applied、奖励唯一性 |
| 2:05—2:35 | 终态后返厅，或明确演示确认退出，再刷新活动 | 先停旧连接、查询恢复，返厅需要服务确认 |
| 2:35—3:00 | 展示测试入口、检查摘要及启动说明 | 真实MySQL／race、模型／真人边界 |

单人现场不要口述为多人实测。没有通关录像时可配合真实截图与源码讲解。用户曾报告最新包联机、整局和返厅完成，但人数、设备、网络及包哈希未补填，不扩大范围。

## 演示前准备

1. 提前检查服务，同版本完整包使用独立演示账号。
2. 一次只启动所需客户端，保留现有内存保护；不临时重跑所有构建／性能测试。
3. 打开[架构与时序](architecture-overview.md)、[可靠性说明](reliability-and-settlement.md)及[当前状态](current-status.md)。
4. 录屏只捕获目标窗口，避免桌面通知、私密目录和授权信息。
