# Dungeon Contract 2.5 玩家说明

当前为v8工程候选，启动工程 `start-v8.cmd`；主机 `start-v8-lan-host.cmd`，玩家从同批完整包的 `start-v8-player.cmd` 启动。新旧版本不可混用。网络配置沿用[联机教程](radmin-human-multiplayer-guide.md)，本轮没有修改VPN或防火墙。

WASD移动，鼠标瞄准；左键当前武器连续普攻，右键仅锤蓄力；Q/滚轮换武器，Space闪避，E/F主动，J交互/救援，R装填，Esc菜单，Tab成长。

锤普攻和重砸落点缩为1.2格，重砸震波仍2.875格。蓄力红光、释放红风和每次落地震波分别表示动作阶段。

工匠F改为死亡锤风：2秒内随人旋转，对2.5格内可见敌人持续伤害并清弹；完整墙柱和掩体会挡住效果。可移动、闪避、E和切武器，期间不能普攻或蓄力，结束后重新按攻击。过门或倒地结束，不退冷却。

双塔成长后E每次放一台，图标显示剩余次数；第二台成功后才冷却12秒。每台寿命独立8秒，第一台到期不会返还次数，可以换个位置再部署第二台。战意成长替换原护盾成长，主动后增伤15%/3秒，双塔每组第一次触发。

镜头在角落继续跟随角色，房外黑区是预期显示。视野和HUD缩放保持一致。

用户已反馈最新既有包完成联机、整局及返厅续局，未发现重大问题；人数、设备和网络条件未逐项登记。已取消的正式联机性能、七项自动通关要求与26项复验保持取消，不写成通过。历史自动化成绩属于各自源码和构建；更新代码后须使用重新校验的同批主机及玩家包。当前已知限制以发行说明或源码中的 docs/portfolio/current-status.md 为准。
